## Что это

Одностраничный сайт риэлтора и юриста по недвижимости: услуги, подборка льготных
ипотечных программ в виде слайдера и каталог из 12 текущих объектов жилого фонда.
Реальный заказчик, реальный контент, продакшн-сборка без фреймворков.

Проект собран вручную: **780 строк HTML**, **2137 строк CSS в 99 файлах**,
**51 строка нативного JS** — и ни одной строки, сгенерированной конструктором.
Swiper подключён как единственная внешняя библиотека.

## Ключевые решения

**Pixel perfect по макету.** Все размеры, отступы, кегли и цвета сняты с макета
Figma и перенесены в код: никаких «на глаз», вертикальный ритм и сетки совпадают
с дизайном на всех контрольных ширинах.

**Строгий БЭМ.** Каждый блок живёт в своей папке (`blocks/<block>/__<element>/`),
94 CSS-файла по одному компоненту, модификаторы — через нижнее подчёркивание
(`object__card-transport-circle_red`, `name_hero`). Один блок — один файл —
одна ответственность: правка кнопки не задевает карточку.

**Дизайн-токены в CSS-переменных.** Палитра вынесена в `vendor/variables.css`:

| Токен | Значение | Где работает |
| --- | --- | --- |
| `--color-dark` | `#2A374A` | Тёмный фон, основной текст, футер |
| `--color-orange` | `#E45438` | Кнопки, акцентные элементы |
| `--color-yellow` | `#D3BF7B` | Дополнительный акцент |
| `--color-grey` | `#a1a1a1` | Подзаголовки, второстепенный текст |
| `--color-light` | `#D9D9D9` | Разделители, линии |
| `--color-white` | `#ffffff` | Фоны секций |

**Три гарнитуры с ролями.** `Marck Script` — рукописное имя в шапке, `Roboto
Condensed` — заголовки, `Roboto` — основной текст. Подключены с
`subset=cyrillic-ext` и `display=swap`, чтобы текст не мигал при загрузке.

**Собственный интерактив без библиотек.** Раскрытие блоков «Подробнее»
и «Показать ещё» написано на нативном JS с поиском по DOM от
`closest('.more-card')`, подменой текста кнопки и CSS-анимацией проявления
(`@keyframes showBlock`). Год в заголовке слайдера и копирайте подставляется
автоматически — сайт не устареет 1 января.

**Адаптив от 360 px без горизонтальной прокрутки.** Четыре контрольные точки —
`1600`, `1024`, `768`, `360` — и собственные значения под каждую: контейнер
меняется `1160 → 800 → 580 → 100%`, каталог перестраивается `3 → 2 → 1` колонка,
карточки услуг из строки становятся колонкой. На 360 px шапка перестраивается
в две строки — имя с подзаголовком сверху, телефон с соцсетями под ними.

## Технический стек

| Слой | Решение |
| --- | --- |
| Разметка | Семантические `section` / `article` / `h1`–`h3`, `lang="ru"` |
| Стили | CSS3, БЭМ-нейминг, CSS-переменные, Flexbox, CSS Grid, `@keyframes` |
| Скрипты | Vanilla JS (ES6+), без jQuery и сборщиков |
| Слайдер | Swiper (loop, autoplay 20 с, кликабельная пагинация) |
| Шрифты | Google Fonts, три гарнитуры, кириллица + `swap` |
| Иконки | SVG: соцсети, иконки транспорта, декоративный орнамент в 3 размерах |
| Хостинг | GitHub Pages (ветка `main`, `.nojekyll`) |

## Как проверено

Страница прогнана через DevTools Protocol на пяти ширинах — `360`, `768`,
`1024`, `1280`, `1920` px:

| Ширина | Горизонтальная прокрутка | Битые изображения | Слайды | Пагинация |
| --- | --- | --- | --- | --- |
| 360 px | 0 px | 0 из 25 | 7 | 7 точек |
| 768 px | 0 px | 0 из 25 | 7 | 7 точек |
| 1024 px | 0 px | 0 из 25 | 7 | 7 точек |
| 1280 px | 0 px | 0 из 25 | 7 | 7 точек |
| 1920 px | 0 px | 0 из 25 | 7 | 7 точек |

Дополнительно проверено поведением, а не только видом:

- **Кнопка «Показать ещё»** — до клика видно 6 карточек объектов, после клика 12, текст меняется на «Скрыть».
- **Карточки «Подробнее»** — список раскрывается, кнопка переключается в «Скрыть», блок появляется с анимацией.
- **Alt-тексты** — заполнены у всех 25 изображений (0 пустых).
- **Подмена изображений на мобильном** — баннер героя меняется на отдельный `hero_sm.jpg`, орнамент переключается между тремя SVG под ширину экрана.
- **Консоль браузера** — пуста, ошибок и предупреждений нет.
- **Адаптивные сетки** — каталог: `360px 360px 360px` → `387.5px 387.5px` → `580px` → `325px`.

## Оптимизация

- **Растр сжат** через [tinypng.com](https://tinypng.com/) — 28 изображений: JPEG для фотографий, PNG для иконок преимуществ.
- **Вектор там, где он уместен** — 10 SVG общим весом 10,2 КБ: иконки соцсетей, транспортные пиктограммы, орнамент разделителя. Иконки-модификаторы подключены фоном через CSS, поэтому масштабируются без потерь.
- **Ленивая загрузка каталога** — 12 JPEG объектов несут `loading="lazy"`:
  до прокрутки грузится только первый экран, остальное подтягивается по мере приближения.
- **Баннер героя подменяется под ширину** — на мобильном грузится отдельный облегчённый `hero_sm.jpg` (176 КБ вместо 378 КБ).
- **`@media` с шагом `.98px`** — исключает «мёртвую зону» на устройствах с дробным device-pixel-ratio.

## Запуск

Сборка не нужна: ни npm, ни транспиляции, ни препроцессоров. Достаточно
клонировать и поднять локальный сервер:

```bash
git clone https://github.com/Artem02031980/polyakova.git
cd polyakova
python -m http.server 8000
```

Затем `http://127.0.0.1:8000/`.

Сервер рекомендован, потому что так проект ведёт себя ровно как на GitHub
Pages. Быстрая проверка возможна и двойным щелчком по `index.html` — стили,
шрифты Google Fonts и изображения подхватываются по `file://` штатно
(замерено: применяются все 5 таблиц стилей, 0 битых изображений).
